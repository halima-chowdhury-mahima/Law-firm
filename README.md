## ✨ Project Overview

**Chowdhury Law Chamber** is a premium law firm website designed with a professional legal brand identity.

The project focuses on:

- Elegant law firm presentation
- Smooth user experience
- Modern responsive design
- Professional legal service sections
- Animated hero content
- Custom law-themed cursor interaction
- Clean and reusable component structure

The design uses a premium **navy, cream and gold** color palette to create a trustworthy and sophisticated legal identity.
